# חיבור הקלטות השיחות של אקסטרה ל-CRM של דשן: משימה לקלוד בדפדפן

> ⚠️ **אם בשורה "סוד ה-webhook" למטה כתוב `__EXTRA_WEBHOOK_SECRET__`:** זו גרסת התבנית. עוצרים ומבקשים מהמשתמש את הקובץ המלא, שבו הסוד כבר ממולא.

## המטרה

הקו הסלולרי של **גלי**, אשת המכירות של **דשן מדיה טק**, עבר לאקסטרה מובייל. אקסטרה מקליטה כל שיחה ברשת עצמה. רוצים שכל שיחה תופיע ב-CRM עם ההקלטה, כדי שמנהלי המערכת (נתנאל) יוכלו לשמוע אותה.

הצד של השרת כבר בנוי ועובד. **התפקיד שלך הוא רק הגדרות:** באזור האישי של אקסטרה וב-Heroku. לא נוגעים בקוד.

### איך זה עובד

1. בסוף כל שיחה אקסטרה שולחת לשרת בקשה (webhook) עם מזהה השיחה.
2. השרת קורא את פרטי השיחה מה-API של אקסטרה ושומר אותם.
3. כשמנהל לוחץ "▶ השמע", השרת מבקש מאקסטרה קישור זמני להקלטה. הקישור תקף 10 דקות.
4. בנוסף, כל 15 דקות השרת מושך מה-API את השיחות האחרונות, כגיבוי אם webhook מסוים לא הגיע.

| פרט | ערך |
|---|---|
| האזור האישי של אקסטרה | https://www.exm.co.il/my/ |
| השרת (Heroku) | האפליקציה `dashen-cpanel`, https://dashboard.heroku.com/apps/dashen-cpanel/settings |
| כתובת ה-webhook | `https://dashen-cpanel-b76c272f93dd.herokuapp.com/api/cpanel/calls/extra-webhook` |
| בדיקת מצב | https://dashen-cpanel-b76c272f93dd.herokuapp.com/api/cpanel/calls/extra-status |
| **סוד ה-webhook** | `__EXTRA_WEBHOOK_SECRET__` |

## חוקים (חובה)

1. **מפתח ה-API של אקסטרה עובר ישר ל-Heroku.** לא כותבים אותו בצ'אט, בקובץ, בהערה או בסיכום, ולא מראים אותו למשתמש.
2. **סוד ה-webhook מהטבלה למעלה מכניסים בשני מקומות בלבד:** Heroku (שלב 3) והאוטומציה באקסטרה (שלב 4). לא כותבים אותו בסיכום.
3. **סיסמאות וקודי אימות מקליד רק המשתמש.** אם צריך להתחבר לאקסטרה או ל-Heroku, מבקשים ממנו.
4. **אף פעם לא בוחרים "קישור ציבורי קבוע" להקלטה,** בשום מקום. קישור כזה פותח את ההקלטה לכל מי שמחזיק בו, לתמיד.
5. **עוצרים ושואלים את המשתמש לפני:**
   - שינוי חבילה, או הזמנה של שירות בתשלום.
   - מחיקה או השבתה של משהו, כולל מפתחות ואוטומציות קיימים.
   - שינוי בהגדרות הקו שלא מופיע במדריך הזה.
6. **מה שלא נמצא, לא מנחשים.** רושמים בסיכום וממשיכים.

## שלב 0: לוודא שהקוד כבר בשרת

פותחים את כתובת בדיקת המצב מהטבלה.

- **"Not Found" או שגיאה:** הקוד החדש עוד לא עלה.
  - **עוצרים כאן,** ואומרים למשתמש לדחוף את הקוד ולחכות שה-deploy ב-Heroku יסתיים.
  - הסיבה: אם האוטומציה באקסטרה תוגדר לפני שהשרת מוכן, היא תיכשל. אקסטרה **משביתה אוטומציה אחרי 3 כישלונות ברצף**.
- **JSON שמתחיל ב-`{"apiKey":false`:** הקוד בשרת. ממשיכים.

## שלב 1: הקו מקליט

1. באזור האישי פותחים את **הקו הסלולרי** ("קווי סלולר חכמים") ונכנסים להגדרות הקו.
2. **רושמים לסיכום:**
   - מספר הקו.
   - האם הקלטת השיחות פעילה.
   - האם יש רשימת מספרים שלא מוקלטים (חריגים).
3. **אם ההקלטה כבויה,** מפעילים אותה, כי זו כל המטרה, ורושמים בסיכום שהופעלה.
4. **ברשימת החריגים לא נוגעים.** רק רושמים מה יש בה.

## שלב 2: מפתח API

1. **לפני שיוצרים מפתח,** פותחים בלשונית נפרדת את הגדרות האפליקציה ב-Heroku ולוחצים "Reveal Config Vars".
2. באקסטרה עוברים לעמוד **"מפתחות ה-API"**: https://www.exm.co.il/my/api/ (באזור האישי זה כנראה האייקון `</>` בתפריט הצד).
3. **מפתחות קיימים:** לא מוחקים ולא משנים.
4. **יוצרים מפתח חדש.** אם אפשר לתת לו שם, השם הוא `Dashen CRM`.
5. **הרשאות:** אם יש בחירה, צריך גישה ל**שיחות ולהקלטות**, וזה הכול. אם אין בחירה, ממשיכים. לפי אקסטרה, מפתח רגיל מגיע להקלטות בלי הרשאה נפרדת.
6. **תאריך תפוגה:** אם מוצג, רושמים אותו בסיכום.
7. מעתיקים את המפתח **ישר** ל-Heroku (שלב 3), בלי לכתוב אותו בשום מקום אחר.

## שלב 3: ערכים ב-Heroku

ב-Config Vars של `dashen-cpanel` מוסיפים **רק** את שני הערכים האלה:

| מפתח | ערך |
|---|---|
| `EXTRA_API_KEY` | המפתח משלב 2 |
| `EXTRA_WEBHOOK_SECRET` | סוד ה-webhook מהטבלה למעלה |

- **לא נוגעים בשום Config Var אחר.**
- אחרי השמירה Heroku מפעיל את השרת מחדש לבד. **מחכים כדקה.**

**בדיקה:** פותחים שוב את כתובת בדיקת המצב. צפוי לראות:
- `"apiKey":true`
- `"webhookSecret":true`
- `"key":"valid"`
- `keyExpires` עם תאריך, אם אקסטרה מחזירים אותו.

**אם הבדיקה לא עוברת:**
- **`"key":"rejected"`:** בודקים שבערך ב-Heroku אין רווח או שורה מיותרים. **לא** יוצרים מפתח נוסף בלי לשאול את המשתמש.
- **`"key":"unreachable"`:** מחכים דקה ובודקים שוב.

## שלב 4: אוטומציה בסוף כל שיחה

**איפה:** באזור האישי ← הקו הסלולרי ← הגדרות ← **"אוטומציות ואינטגרציה"** ← **"הוספת אוטומציה"**. רשימת האוטומציות נמצאת גם ב-https://www.exm.co.il/my/automations/.

**השדות:**

| שדה | ערך |
|---|---|
| שם, אם יש | `Dashen CRM — סיום שיחה` |
| אירוע | **סיום שיחה**, של הקו הסלולרי של גלי |
| פעולה | **שליחת בקשת HTTP** |
| Method | `POST` |
| URL | `https://dashen-cpanel-b76c272f93dd.herokuapp.com/api/cpanel/calls/extra-webhook` |
| Content-Type | `application/json` |
| אימות | **Bearer token**, והערך הוא סוד ה-webhook מהטבלה למעלה |
| קישור להקלטת השיחה | **לא לבחור.** אם חייבים לבחור משהו, בוחרים **קישור זמני**, **אף פעם לא** "ציבורי קבוע" |

**האימות:** אם אין אפשרות של Bearer, בוחרים **"מפתח API ב-Header מותאם"**:
- שם ה-header: `x-webhook-secret`
- הערך: הסוד

השרת מקבל את שתי הדרכים.

**גוף הבקשה:** מעתיקים בדיוק כך, עם הסוגריים המסולסלים הכפולים. אקסטרה מחליפה אותם בערכים:

```json
{"id": "{{ id }}", "event": "{{ event }}", "type": "{{ type }}"}
```

- **רק שלושת המשתנים האלה.** את שאר פרטי השיחה השרת קורא בעצמו מה-API.
- **לא מוסיפים `{{ contact.name }}`.** שם עם מרכאות (למשל בע"מ) עלול לשבור את ה-JSON.

**בסוף:** שומרים ומוודאים שהאוטומציה **פעילה**.

## שלב 5: שיחת בדיקה

1. **מבקשים מהמשתמש שיחת בדיקה של לפחות 10 שניות,** עם מענה. אפשר להתקשר לקו של גלי, או שגלי תתקשר למישהו. שיחה של 6 שניות או פחות לא מוקלטת.
2. **כדקה אחרי שהשיחה נגמרת,** בודקים שני דברים:
   - **ביומן הפעילות של האוטומציה באקסטרה** צריכה להופיע בקשה עם קוד **200**.
   - **בכתובת בדיקת המצב,** `lastWebhookAt` צריך להתעדכן לזמן השיחה.
3. **אם ביומן מופיע קוד אחר:**

   | קוד | המשמעות | מה עושים |
   |---|---|---|
   | **401** | הסוד ב-Heroku ובאוטומציה לא זהה | מתקנים את הערך באוטומציה |
   | **404** | ה-URL שגוי, או שהקוד לא עלה | בודקים את ה-URL ואת שלב 0 |

   - **אחרי כישלון אחד מתקנים, ורק אז מבקשים שיחת בדיקה נוספת.** שלושה כישלונות ברצף משביתים את האוטומציה.
   - אם היא הושבתה: לוחצים "הפעלה מחדש" במסך האוטומציות.
4. **את הבדיקה בפאנל עושה המשתמש:**
   - בפאנל: **ניהול ראשי ← "הקלטות שיחות"**.
   - השיחה צריכה להופיע שם, ו-"▶ השמע" צריך לנגן אותה.
   - המסך זמין רק למנהלי מערכת.

## בסוף: סיכום למשתמש

כותבים בעברית, **בלי מפתח ה-API ובלי סוד ה-webhook**:

- **הקו:**
  - מספר הקו.
  - האם ההקלטה פעילה, והאם הופעלה עכשיו.
  - מה יש ברשימת החריגים.
- **מפתח API:**
  - האם נוצר ונשמר ב-Heroku: **רק "כן" או "לא".**
  - תאריך התפוגה.
- **`EXTRA_WEBHOOK_SECRET`:** האם נשמר ב-Heroku, **רק "כן" או "לא".**
- **האוטומציה:**
  - האם נוצרה.
  - האירוע, ה-URL וסוג האימות (**בלי הסוד**).
  - האם היא פעילה.
- **בדיקת המצב:** התוצאה של `extra-status`.
- **שיחת הבדיקה:** הקוד ביומן הפעילות, והאם `lastWebhookAt` התעדכן.
- **מה לא נמצא, ושאלות פתוחות.**

את הסיכום הזה המשתמש יעביר ל-Claude Code של הפאנל.
